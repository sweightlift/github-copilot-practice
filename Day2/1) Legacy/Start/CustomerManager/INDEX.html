AI Agent Chat (CopilotKit)

The AI Agent now has two interfaces:

1. CopilotKit UI (Recommended) — Open the Next.js frontend with the CopilotSidebar chat widget:

⚡ Open CopilotKit UI (localhost:3333)

2. Legacy API — Use PowerShell/curl to call /api/chat directly:

## PowerShell $body = @{ message = "List all customers" } | ConvertTo-Json Invoke-RestMethod -Uri "http://localhost:5000/api/chat" ` -Method Post -Body $body -ContentType "application/json" ## curl curl -X POST http://localhost:5000/api/chat \ -H "Content-Type: application/json" \ -d '{"message": "Search for Jane"}'
⚡ Open Swagger UI
Example prompts: "List all customers" • "Search for Jane" • "Add a customer named Test User with email test@mail.com" • "Delete customer 4"
